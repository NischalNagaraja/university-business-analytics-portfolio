## Reading the evidence

These files are text extracts of archived academic reports. Original report wording and references are retained; text extraction can lose diagrams, tables and formatting. They demonstrate the documented scope of the academic work, not independently reproduced model performance or deployed commercial results. Proposed business improvements are recommendations, not achieved outcomes.

Student identifiers and contact details are removed. Raw datasets, university marks statements and the private chat export are not published here. Example insurance code naming other authors is excluded. The reports' numerical statements should be checked against original data and outputs before reuse in applications.
